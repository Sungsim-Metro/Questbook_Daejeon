# 꿈돌이 누적 완료 해금

도감의 정본은 `/api/ggumdori`다. 카테고리별 성공 1회에 Lv.1, 2회에 Lv.2,
3회에 Lv.3을 지급한다. 기본 꿈돌이는 가입 시 지급한다. 뱃지와 사용자 레벨은
기존 XP 정책을 유지한다.

실제 `quest_completions`만 집계하므로 추천·수락·인증 실패는 횟수에 포함되지 않는다.
같은 완료 요청의 재전송은 중복 집계하지 않으며 사용자별로 분리한다.
수락 당시 저장한 퀘스트 사본을 사용하므로 공용 퀘스트가 변경·삭제돼도 완료 횟수가 유지된다.
기존 완료 기록은 도감 조회 또는 다음 완료 시 소급 지급한다. 이미 지급된 소유권·획득일·대표 설정은 보존한다.

기존 관광지 분류는 `domain/ggumdori_rewards.py`의 `completion_theme()`로 보상 테마에 연결한다.
예를 들어 상권 퀘스트 중 성심당·베이커리는 빵, 칼국수·식당은 음식으로 분류한다.
명시적인 새 카테고리가 우선하며, 이전 넓은 분류에만 저장된 장소·제목의 키워드를 적용한다.
한 완료는 한 테마에만 포함된다. 추천 응답의 `quest.rewardCategory`도 같은 함수를 사용한다.

서버 등록부는 기본 1종 + 11개 테마 × 3단계 = 34종이다.
새 이미지가 있는 9개 테마는 `*_lv1_128.png` ~ `*_lv3_128.png`를 사용한다.
자연·문화는 기존 1~3단계 PNG를 사용한다. GIF·1024px 파일은 같은 보상의 다른 표현이므로
별도 보상으로 등록하지 않는다. 야경 variant는 공개 도감과 신규 지급에서 제외한다.
기존 이미지 파일은 과거 화면 참조와 원본 보존을 위해 삭제하지 않는다.

이미지 등록부를 변경했다면 저장소 루트에서 실행한다.

```powershell
services/app-api/.venv/Scripts/python.exe scripts/sync_ggumdori_manifest.py
services/app-api/.venv/Scripts/python.exe scripts/sync_ggumdori_manifest.py --check
```

서버 재시작 시 기존 ID를 유지하는 upsert로 이미지·이름·조건을 갱신한다.
도감 카드는 누적 횟수와 요구 횟수를 보여 주며, 대표 설정은 서버의 실제 소유권으로 검사한다.
